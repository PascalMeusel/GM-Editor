# GM Editor community preview

GM Editor is a Windows desktop tool for preparing tabletop RPG sessions and
presenting selected information on a local player screen. Prepare scenes, link
people and places, generate connected maps, and run the prepared session.

**Public source preview — 10 November 2026.** The current source is available at
[PascalMeusel/GM-Editor](https://github.com/PascalMeusel/GM-Editor). Build it using
the instructions below; a packaged Windows download has not been published yet.
Project code is free under GPL-3.0-or-later. Selected project artwork is CC BY 4.0;
other third-party material retains its own terms. See [licensing](../../LICENSING.md).

## What to expect

- Session planning, linked campaign notes, characters, encounters and inventories.
- World, region and outdoor tactical map generation and editing.
- A local player window with explicit controls over shared information.
- Campaign save, export/import and recovery workflows.
- Reviewed session outcomes, consequences and selected carry-forward into the next session.
- Explicitly reviewed player recaps, Markdown note exchange and tactical Universal VTT export.
- English and German interface support with some specialist labels still pending.

There is no hosted multiplayer service or remote player client. Settlement,
dungeon and cave generation are experimental. The application has automated test
coverage, but recurring sessions with unfamiliar human GMs remain under-tested.
Keep backups and use a copy of a campaign when trying the preview.
