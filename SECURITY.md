# Security reporting

The project is an experimental desktop application. No version currently carries
a long-term security-support commitment.

Use [GitHub private vulnerability reporting](https://github.com/PascalMeusel/GM-Editor/security/advisories/new)
or **Security → Advisories → Report a vulnerability** on the official repository.
Include the affected version, reproduction steps using fictional data,
and the impact. Do not disclose credentials, private campaigns or exploit details
in a public issue. If that button is unavailable, open a minimal issue asking for
a private reporting channel, without sensitive details.

Relevant reports include campaign import path traversal, unsafe archive handling,
data loss, unintended GM-information exposure, and unsafe build or release
automation. The maintainer will investigate when available; there is no paid
response-time promise or bug-bounty program.
